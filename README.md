# Maison Dorée Web ✨

A responsive luxury artisan gold jewelry website built with HTML5, CSS3, and Bootstrap 5.

## 📌 Features
- **Responsive Navigation:** Navbar with collapsible mobile menu, smooth brand styling, and appointment booking CTA.
- **Hero Carousel:** Timed auto-sliding showcase displaying luxury jewelry imagery.
- **Featured Piece Section:** Detailed product highlight (Aurora Pendant) with 22K gold technical specifications and inquiry action.
- **Curated Collections Grid:** Asymmetrical multi-image product showcase.
- **Heritage Story Section:** Atelier history, brand narrative, and leadership spotlight.

## 💻 Tech Stack
- **HTML5:** Semantic architecture.
- **CSS3:** Custom luxury typography, Cormorant Garamond font, and spacing utilities.
- **Bootstrap 5.3:** Grid system, carousel component, and responsive flex utilities.
